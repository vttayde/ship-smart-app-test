## 🎯 **Project Overview**

**Ship Smart** is a logistics aggregation platform that connects consumers with multiple courier service providers (Delhivery, Shadowfax, Ekart) through a unified booking and tracking system.

### **Key Features:**
- 🚚 **Multi-Courier Integration** - Compare prices from multiple providers
- 🔍 **Smart Comparison** - Find best rates and delivery options
- 🔐 **Guest Browsing** - Authentication only required for booking
- 📱 **Real-time Tracking** - Live GPS tracking across all partners
- 💳 **Secure Payments** - Integrated payment processing

## 🏗️ **Technology Stack**

### **Full-Stack Framework**
- **Framework**: Next.js 15 + TypeScript (Frontend + Backend)
- **Frontend**: React components, Server-Side Rendering, App Router
- **Backend**: Next.js API Routes (/api/*) with serverless functions
- **Styling**: Tailwind CSS + shadcn/ui
- **State Management**: Zustand
- **Database**: PostgreSQL + Prisma ORM (ACID compliance)
- **Authentication**: NextAuth.js + JWT
- **Security**: Row-Level Security + Server-side validation
- **Deployment**: Vercel (Full-stack, Auto-scaling)

### **Integrations**
- **Payment**: Razorpay Gateway
- **Maps**: Google Maps API
- **SMS/Email**: Twilio + SendGrid
- **Courier APIs**: Delhivery, Shadowfax, Ekart
